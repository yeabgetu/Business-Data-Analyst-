# E-Commerce Product Analytics

## 📊 Project Overview

An end-to-end e-commerce analytics project focused on understanding **product performance, customer behavior, sales trends, and business opportunities**.

The project combines **SQL, Python, and Power BI** to clean, analyze, and visualize e-commerce data and turn it into actionable business insights.

## 🎯 Business Problem

The business needs better visibility into its sales and product performance to understand:

- Which products and categories generate the most revenue
- How customers interact with and purchase products
- Where sales opportunities and performance gaps exist
- How revenue and customer activity change over time

## 🔍 Key Analysis

### Product Performance
- Analyzed revenue by product and category
- Identified top-performing and underperforming products
- Examined product contribution to overall revenue

### Customer Analysis
- Analyzed customer purchasing behavior
- Compared customer segments and spending patterns
- Examined repeat purchasing behavior

### Sales Analysis
- Analyzed revenue and order trends over time
- Evaluated sales performance across different segments
- Identified patterns that could support business decisions

### Advanced SQL Analysis
Used advanced SQL techniques including:

- CTEs
- Window functions
- Subqueries
- CASE statements
- Revenue concentration analysis
- Customer segmentation
- Funnel analysis
- Cohort-style analysis

## 🛠️ Tools & Technologies

- **SQL / PostgreSQL** — Data analysis and business queries
- **Python** — Data cleaning and exploratory analysis
- **Power BI** — Interactive dashboard and visualization
- **Power Query** — Data transformation
- **Excel / CSV** — Data storage and preparation

## 📈 Dashboard

The Power BI dashboard brings the analysis together through interactive visualizations covering:

- Sales and revenue performance
- Product and category performance
- Customer behavior
- Sales trends
- Key business KPIs

The cleaned datasets are included so the analysis and dashboard can be reproduced and refreshed.

## 🧹 Data Preparation

The raw data was processed before analysis to address common data-quality issues, including:

- Missing values
- Duplicate records
- Inconsistent formats
- Data validation
- Transformation of fields required for analysis

## 💡 Business Insights

The analysis is designed to translate technical findings into business-focused insights that can support:

- Product and inventory decisions
- Customer strategy
- Sales planning
- Performance monitoring
- Identification of growth opportunities

## ⚠️ Challenges & Limitations

- Some business metrics required assumptions because complete tracking data was unavailable.
- The dataset is simulated and may not represent every real-world e-commerce scenario.
- Data aggregation can limit detailed analysis at certain levels.
- Complex SQL queries required careful validation to maintain accurate results.
- Different tools required adapting calculations and data-transformation logic.

## 🚀 Project Outcome

This project demonstrates an end-to-end analytics workflow:

**Raw Data → Data Cleaning → SQL & Python Analysis → Power BI Dashboard → Business Insights**

It showcases my ability to work with data across multiple tools and communicate analytical findings in a way that supports business decision-making.
