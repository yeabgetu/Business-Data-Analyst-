# Data

This folder contains the raw datasets used for the e-commerce product analysis.

## Files

- `order_data_unclean.csv` — unclean raw purchasing-session and order information
- `web_session_unclean.csv` — unclean rawWebsite session and conversion information

- `orders_clean.csv` — Completed purchasing-session and order information
- `web_session_clean.csv` — Website session and conversion information
